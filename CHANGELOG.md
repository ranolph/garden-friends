# Changelog

## 1.0.0

- Introduces the Garden Friends distribution of the Avian Visitors wildlife dashboard.
- Adds a Statistics-accessible settings page for InfluxDB, MQTT, BirdNET, Frigate and Home Assistant discovery.
- Adds administrator setup, login, connection checks and managed application restarts after configuration changes.
- Uses midnight-to-midnight days in the configured timezone, including daylight-saving transitions.
- Packages the complete static artwork collection with filenames, checksums and a generated gallery.
- Includes container deployment, release verification and GitHub publishing instructions.
- Keeps the public display and the GitHub profile link available without an administrator login.
